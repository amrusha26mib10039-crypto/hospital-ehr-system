# Hospital Patient & Electronic Health Record (EHR) System

## 1. Overview

This is a Python-based project that allows the management of basic information and records of patients in hospitals.

This software enables hospital personnel to register patients, manage doctor information, generate prescriptions via the chemist department and generate billing information.

This project shows how the Python programming language can be used in developing a simple hospital records management system.

## 2. Features

-Patient registration
-Patient information management
-Doctor department for recording diagnosis and other relevant information
-Recording patient allergies
-Prescription handling
-Chemist department for medicine operations
-Medicine billing
-Simple and easy-to-use menu-driven interface
-Patient record management

## 5. Installation & Running the Project
Step 1: Clone the repository: Clone the project repository from GitHub.
Step 2: Open the project: Open the project folder in Visual Studio Code.
Step 3: Ensure Python is installed.
Step 4: Run the project: Run the main Python file: python main.py
Step 5: Use the menu: Use the menu provided by the program to perform required hospital operations.
